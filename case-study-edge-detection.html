Project Summary & Vision Pipeline

This case study documents the engineering blueprint of a custom Canny Edge Detection and Spatial Vector-Tracing engine implemented entirely from scratch in native C++. Designed as a high-performance alternative to monolithic computer vision frameworks, this implementation delivers highly precise structural boundary outlines optimized specifically for injection into parametric CAD software (e.g. SolidWorks, FreeCAD, etc.). By achieving full mathematical and structural sovereignty, the engine bypasses standard performance bottlenecks, features dynamic auto-calibration parameters with real-time UI overrides, and completely eliminates geometric artifacts (such as webbing) during vector synthesis.

Engineering Blueprint & Archetecture: The custom engine architecture breaks down into an isolated, five-stage pipeline designed around strict memory management and high-throughput execution grids: 2D Separable Filter Engine, Vector Arithmetic Processor, Spatial Neighborhood Scanner, State-Driven Pivot Tracker (Hysteresis), Single-File Coordinate Tracker (for SVG Generation).

Technical Achievements

2D Separable Filter Engine: To eliminate the intensive memory footprint of full 2D matrix convolutions, processing is executed using separable 1D horizontal and vertical passes natively across a flat memory array.

Vector Arithmetic Processor: Converts raw spatial gradients into directional edge sectors. It entirely bypasses heavy trigonometric expansions (atan2) in favor of atomic geometric slope vector comparison tests, boosting raw calculation velocity.

Spatial Neighborhood Scanner (Non-Maximum Suppression): Eradicates blurry gradient bands by scanning discrete, clockwise neighbor maps, safely locking pixel edges down to a strict 1-pixel-wide line.

State-Driven Pivot Tracker (Hysteresis): Categorizes edges through a double-threshold matrix. To guarantee zero risk of stack overflow crashes on high-resolution image assets, recursion is completely replaced by a heap-allocated, non-recursive queue structure (Breadth-First Search).

Single-File Coordinate Tracker (SVG Generation): Walks pixel paths sequentially using an instant-break Depth-First Traversal. Continuous strands are group-compiled, consuming pixels to avoid reprocessing, generating un-webbed vector arrays for low-overhead parametric CAD imports.

The Sovereignty Advantage: Custom Engineering vs. OpenCV

While a monolithic library like OpenCV provides broad utility, constructing an algorithm natively from scratch yields immense architectural and operational advantages for specialized pipelines including: Micro-Architectural Separation of Concerns, Mathematical Normalization at the Source, Control Over Geometric Topology, and Freedom from Binary Bloat and Dependency Chains.
